# Ручная проверка перед использованием

Статус: физические Android-устройства в этой среде недоступны, пункты ниже пока не подтверждены.

- Установить APK на два телефона Android 8+; проверить портретный/альбомный экран, большие шрифты, системные отступы и TalkBack.
- Подключить два разных аккаунта к одному TLS-серверу и каналу, проверить список участников.
- Передать речь в обе стороны; проверить громкость, наушники, разборчивость и задержку.
- Одновременно запросить эфир: звук должен передаваться только от одного клиента.
- Отпустить кнопку, увести палец, открыть другой экран: микрофон должен остановиться.
- Удерживать кнопку >30 секунд: сервер должен освободить эфир.
- Проверить сворачивание, поворот, блокировку экрана, входящий звонок и отзыв разрешения микрофона.
- Отключить Wi-Fi/мобильную сеть: клиент должен завершить соединение; повторное подключение вручную.
- Подключить аккаунты к разным каналам: звук между каналами не должен передаваться.
- Проверить ошибочный ключ, недоступный канал, просроченный/неверный сертификат и повторный вход одного аккаунта.
- Проверить часовой таймаут и необходимость повторного ввода ключа.
